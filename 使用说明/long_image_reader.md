# 长图分段阅读

- 插件 id：`long_image_reader`
- 版本：`1`
- 分类：媒体
- 源包：`长图分段阅读-long_image_reader.zip`（打包时取其 `long_image_reader.py`）

## 功能

长截图按从上到下分段并留重叠区，由现有视觉模型读取；超出预算或某段失败会明确标注未读。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用 | bool | （无） |  |
| `maxTiles` | 每张长图最多分段数 | int | （无） |  |

- 插件是会被 import 执行的代码，装之前请先看「检查」结果与上面的配置项。
