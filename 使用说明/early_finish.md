# 提前收尾（省 token）

- 插件 id：`early_finish`
- 版本：`1`
- 分类：实用
- 源包：`提前收尾（省 token）-early_finish.zip`（打包时取其 `early_finish.py`）

## 功能

移植自 JS 插件 early-finish。已交付完毕、没有遗留动作的这一轮，不再为可选的锦上添花动作多花一次模型调用：跳过“该不该接话”的判定调用和“让 AI 选表情”的选择调用。有工具失败、结尾是“我去看看”这类预告、或预告要交图却没交时，一律按正常流程走。不碰提示词、不改人设、不拦发言；“试运行”只记日志不真的省。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用提前收尾 | bool | （无） |  |
| `dryRun` | 试运行（只记录，不真的省调用） | bool | （无） |  |
| `skipJudge` | 跳过“该不该接话”的判定调用 | bool | （无） |  |
| `skipAiReaction` | 跳过“让 AI 选表情”的选择调用 | bool | （无） |  |
| `windowSec` | 只对最近多少秒内交付的这一轮生效 | int | （无） |  |

## 风险与边界

- 插件是会被 import 执行的代码，装之前请先看「检查」结果与上面的配置项。
- 安装器会拦截 os.system / subprocess / eval / exec / socket / ctypes / pickle / winreg 等用法；本包已通过该检查。
- 主动发言、外发类能力默认关闭，必须由你在插件页显式启用才会生效。
- 本页说明取自源包清单，未对插件行为做额外审计；第三方插件的行为自负。
