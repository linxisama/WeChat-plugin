# 人设存档隔离

- 插件 id：`archive_isolation`
- 版本：`1`
- 分类：实用
- 源包：`人设存档隔离-archive_isolation.zip`（打包时取其 `archive_isolation.py`）

## 功能

切换人设后分开对话历史与个人记忆，再切回来可继续原有存档；不会删除或搬走用户文件。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用 | bool | （无） |  |
| `protectKeys` | 共用记忆的会话（group:ID 或 private:ID，逗号分隔） | string | （无） |  |

## 风险与边界
