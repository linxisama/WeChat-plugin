# 群友花费统计

- 插件 id：`group_cost_report`
- 版本：`1`
- 分类：实用
- 源包：`群友花费统计-group_cost_report.zip`（打包时取其 `group_cost_report.py`）

## 功能

移植自社区插件 group-cost-report：群里 @机器人 说「金额统计」（可跟区间：昨天 / 本周 / 上月 / 最近7天 / 9月1日到9月30日 / 全部…），就把这段时间本群的 token 用量按**触发这次运行的人**逐人列出来。规则触发、立即回复，**不经过模型、零消耗**。填了单价（元/百万 token）才折算金额，没填就只报 token。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用花费统计 | bool | （无） |  |
| `triggerWords` | 触发关键词（逗号分隔） | string | （无） |  |
| `allowWithoutAt` | 不需要 @ 也触发（容易误触发） | bool | （无） |  |
| `defaultRange` | 默认统计区间 | select | （无） |  |
| `topN` | 最多列出几人 | int | （无） |  |
| `maxRows` | 单次最多扫描多少条运行记录 | int | （无） |  |
| `footer` | 报告末尾附统计口径 | bool | （无） |  |
| `priceIn` | 输入单价（元/百万 token，0=不折算） | float | （无） |  |
| `priceOut` | 输出单价（元/百万 token，0=不折算） | float | （无） |  |
