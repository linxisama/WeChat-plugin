# 正在输入提示

- 插件 id：`typing_indicator`
- 版本：`1`
- 分类：实用
- 源包：`正在输入提示-typing_indicator.zip`（打包时取其 `typing_indicator.py`）

## 功能

私聊（可选群聊）里让机器人像真人一样亮起「正在输入…」：从它决定要回话到消息发出之间，对方会看到正在输入。零 token：不改提示词、不注册工具、不调模型，只在对的时机补发状态包。（需要协议端支持 set_input_status；官方接口不支持，此模式下不生效。）

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用 | bool | （无） |  |
| `showTyping` | 显示输入提示 | bool | （无） | 关掉后不再发状态包（与原开关语义一致）。 |
| `privateOnly` | 只在私聊生效 | bool | （无） | 默认开。群聊里「正在输入」观感因协议端而异，需要就关掉这项。 |
| `eventType` | 状态类型 | select | （无） | typing = 正在输入（默认）；speaking = 正在讲话（录音中）。 |
| `cooldownSec` | 同一会话冷却（秒） | int | （无） | 默认 5：短时间内连续回复时不重复发状态包。 |
| `minDelayMs` | 预计很快回时不发（毫秒） | int | （无） | 默认 0（总是发）。填 800 这类值可以避免「秒回」时闪一下正在输入；判定依据是上一条消息距今的时间（消息来得太密时就不发状态）。 |

## 风险与边界

- 插件是会被 import 执行的代码，装之前请先看「检查」结果与上面的配置项。
- 安装器会拦截 os.system / subprocess / eval / exec / socket / ctypes / pickle / winreg 等用法；本包已通过该检查。
- 主动发言、外发类能力默认关闭，必须由你在插件页显式启用才会生效。
- 本页说明取自源包清单，未对插件行为做额外审计；第三方插件的行为自负。
