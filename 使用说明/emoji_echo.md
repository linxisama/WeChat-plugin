# 跟着贴表情

- 插件 id：`emoji_echo`
- 版本：`1`
- 分类：社交
- 源包：`跟着贴表情-emoji_echo.zip`（打包时取其 `emoji_echo.py`）

## 功能

普通QQ/OneBot专用：群友给消息贴表情回应时，跟贴同一条消息的同一个表情，全程不调用模型、不发文字。当前官方QQ群聊接入不支持此动作，会保持不执行；图片表情不受影响。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用跟贴 | bool | （无） |  |
| `delayMs` | 跟贴延迟（毫秒） | int | （无） |  |
| `minIntervalMs` | 最小间隔（毫秒） | int | （无） |  |
| `maxPerMinute` | 每分钟最多次数 | int | （无） |  |
| `groupWhitelist` | 只在这些群生效（逗号分隔） | string | （无） |  |
| `emojiBlacklist` | 不跟贴的表情编号（逗号分隔） | string | （无） |  |
| `followRemove` | 跟随取消表情 | bool | （无） |  |

## 风险与边界

- 插件是会被 import 执行的代码，装之前请先看「检查」结果与上面的配置项。
- 安装器会拦截 os.system / subprocess / eval / exec / socket / ctypes / pickle / winreg 等用法；本包已通过该检查。
- 主动发言、外发类能力默认关闭，必须由你在插件页显式启用才会生效。
- 本页说明取自源包清单，未对插件行为做额外审计；第三方插件的行为自负。
