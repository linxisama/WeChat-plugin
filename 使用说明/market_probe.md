# 市场探针

- 插件 id：`market_probe`
- 版本：`1`
- 分类：实用
- 源包：`市场探针-market_probe.zip`（打包时取其 `market_probe.py`）

## 功能

抓取插件市场目录并按关键词筛出相关插件，结果只展示、不自动安装。默认指向 QQ Agent 社区市场（kondius.cn/api/community/plugins），清单里会标出哪些本项目已经移植过、哪些评估过但不适用；也支持通用 JSON 目录（{"plugins":[{name,url,description,tags}]}）与常见 HTML 目录页。管理员在 QQ 私聊里发“市场 [关键词]”，或在管理员模式下直接发“市场”。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用市场探针 | bool | （无） |  |
| `marketUrl` | 市场目录地址（http/https） | string | （无） |  |
| `keywords` | 默认关键词（逗号分隔，留空=全部） | string | （无） |  |
| `maxItems` | 最多展示条数 | int | （无） |  |
| `timeoutSec` | 抓取超时（秒） | int | （无） |  |

## 风险与边界

- 插件是会被 import 执行的代码，装之前请先看「检查」结果与上面的配置项。
- 安装器会拦截 os.system / subprocess / eval / exec / socket / ctypes / pickle / winreg 等用法；本包已通过该检查。
- 主动发言、外发类能力默认关闭，必须由你在插件页显式启用才会生效。
- 本页说明取自源包清单，未对插件行为做额外审计；第三方插件的行为自负。
