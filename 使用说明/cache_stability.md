# 缓存稳定性

- 插件 id：`cache_stability`
- 版本：`1`
- 分类：实用
- 源包：`缓存稳定性-cache_stability.zip`（打包时取其 `cache_stability.py`）

## 功能

移植自社区插件 cache-stability。把"每轮都会变"的说明排到系统提示词最后，让发送前缀尽量逐字节相同 —— 服务商按前缀缓存计费，命中部分便宜一个数量级。同时把真实的缓存命中 token 记进运行记录，并在稳定前缀发生变化（改了人设或稳定说明）时提醒你"缓存会重新预热"。关掉它就回到原来的顺序，行为与未安装时一致。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用缓存稳定性 | bool | （无） |  |
| `stableOrder` | 稳定说明在前、易变说明在后 | bool | （无） |  |
| `reportEvery` | 每多少轮记录一次命中率 | int | （无） |  |
| `verbose` | 每次前缀变化都记录 | bool | （无） |  |
