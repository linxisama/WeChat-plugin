# 表情包库上限

- 插件 id：`sticker_cap`
- 版本：`1`
- 分类：媒体
- 源包：`表情包库上限-sticker_cap.zip`（打包时取其 `sticker_cap.py`）

## 功能

防止有人一直发表情包把库和磁盘撑爆：按数量上限做 LRU 淘汰、按磁盘配额清理、可屏蔽指定人的表情。只管理机器人实际收藏的表情库和索引，不删除外部目录或手动图库；收集由“偷表情包”插件完成，/表情容量 可查看用量。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用 | bool | （无） |  |
| `stickerDir` | 表情库目录 | string | （无） | 兼容旧配置；当前运行时固定管理 data/sticker_library，只会清理索引登记的收藏图片。 |
| `maxItems` | 最多存多少个 | int | （无） | 0 = 不限制。超过后按最久未用淘汰。 |
| `maxSizeMb` | 磁盘配额（MB） | int | （无） | 0 = 不限制。超过后按最久未用删除，直到降到配额以内。 |
| `blockedSenders` | 不收这些人的表情 | string | （无） | 逗号分隔 QQ 号。 |
| `dryRun` | 只统计不删除 | bool | （无） | 默认开（安全）：先看看会删多少，确认后再关掉真正执行。 |
| `checkIntervalSec` | 检查间隔（秒） | int | （无） | 默认 3600。 |

## 风险与边界

- 插件是会被 import 执行的代码，装之前请先看「检查」结果与上面的配置项。
- 安装器会拦截 os.system / subprocess / eval / exec / socket / ctypes / pickle / winreg 等用法；本包已通过该检查。
- 主动发言、外发类能力默认关闭，必须由你在插件页显式启用才会生效。
- 本页说明取自源包清单，未对插件行为做额外审计；第三方插件的行为自负。
