# 回复时机与引用

- 插件 id：`reply_freshness`
- 版本：`1`
- 分类：社交
- 源包：`回复时机与引用-reply_freshness.zip`（打包时取其 `reply_freshness.py`）

## 功能

移植自社区插件 reply-freshness：把"现在几点、群里最新一条是谁、你要回的那条还新不新鲜"算清楚，追加在当前这条消息末尾（不动系统提示词，不伤前缀缓存）。晚回就自然补一句衔接；群里冷场时提醒她别为了清空未读继续回旧消息。另有可选的硬刹车「冷场就不回」（默认关）：真的安静下来又没人点她时，本轮不发。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用回复时机提示 | bool | （无） |  |
| `quietSeconds` | 安静多少秒算冷场 | int | （无） |  |
| `lateReplySeconds` | 超过多少秒算晚回 | int | （无） |  |
| `coldAdvice` | 冷场时提醒"别硬接" | bool | （无） |  |
| `coldHold` | 冷场且没人点她时干脆不回（默认关） | bool | （无） |  |
| `announce` | 注入时序说明 | bool | （无） |  |
| `scanLimit` | 回看多少条记录算时序 | int | （无） |  |
| `verbose` | 在控制台记录时序判断 | bool | （无） |  |

## 风险与边界

- 主动发言、外发类能力默认关闭，必须由你在插件页显式启用才会生效。
