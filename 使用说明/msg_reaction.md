# 消息表情回应

- 插件 id：`msg_reaction`
- 版本：`1`
- 分类：社交
- 源包：`消息表情回应-msg_reaction.zip`（打包时取其 `msg_reaction.py`）

## 功能

普通QQ群聊专用：/贴表情 128077 或“给我点个赞”可给消息气泡贴反应；可按概率自动贴，支持AI选表情及随机模式、冷却和小时/每日上限。官方QQ群聊当前不执行此动作，会明确说明。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用消息表情回应 | bool | （无） |  |
| `mode` | 自动表情选择 | select | （无） |  |
| `target` | 自动贴到哪条消息 | select | （无） |  |
| `probabilityPercent` | 自动贴表情概率（%） | int | （无） |  |
| `minGapSec` | 自动动作冷却（秒） | int | （无） |  |
| `maxPerHour` | 每小时最多自动次数 | int | （无） |  |
| `maxPerDay` | 每天最多自动次数 | int | （无） |  |
| `emojiIds` | 可选表情编号（逗号分隔） | string | （无） |  |
| `delaySec` | 自动动作延迟（秒） | int | （无） |  |

## 风险与边界

- 插件是会被 import 执行的代码，装之前请先看「检查」结果与上面的配置项。
- 安装器会拦截 os.system / subprocess / eval / exec / socket / ctypes / pickle / winreg 等用法；本包已通过该检查。
- 主动发言、外发类能力默认关闭，必须由你在插件页显式启用才会生效。
- 本页说明取自源包清单，未对插件行为做额外审计；第三方插件的行为自负。
