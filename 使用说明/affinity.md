# 群友好感度

- 插件 id：`affinity`
- 版本：`1`
- 分类：社交
- 源包：`群友好感度-affinity.zip`（打包时取其 `affinity.py`）

## 功能

移植自社区插件 affinity：自动给每个群友累积好感度 —— 发言加分、@机器人加分、接话加分，每人每天有上限防刷屏；长期不发言缓慢衰减；主人恒为满级。等级：陌生/眼熟/熟人/老友/挚友。当前说话人的真实分数与等级会作为"易变说明"注入提示词，问到"你我多熟"时不会编数字。口令：好感度 / 好感度 排行 [N] / 好感度 重置 [QQ号]（主人）/ 好感度 设置 <键>=<值>（主人），全部零消耗。

## 安装

1. 打开控制台 ->「插件中心」；
2. 点「添加插件」->「本地文件」，选择本压缩包；
3. 先点「检查」，确认名称、说明与安全检查通过；
4. 确认无误后安装（更新时勾选「覆盖同名插件」）。

装完不会自动生效：到插件页手动启用并按需调参数。不需要时在插件中心删除。

## 配置项

| 键 | 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 启用好感度 | bool | （无） |  |
| `perMessage` | 每条发言加分 | int | （无） |  |
| `atBotBonus` | @机器人额外加分 | int | （无） |  |
| `replyBonus` | 接话额外加分 | int | （无） |  |
| `dailyCap` | 每人每天加分上限 | int | （无） |  |
| `decayAfterDays` | 多少天不发言开始衰减 | int | （无） |  |
| `decayPerDay` | 每天衰减多少分 | int | （无） |  |
| `replyWindowSec` | 多久内算"接话"（秒） | int | （无） |  |
| `scanLimit` | 每次补扫的聊天记录条数 | int | （无） |  |
| `backfillSeconds` | 同一会话最短多久补扫一次（秒） | int | （无） |  |
| `topN` | 排行榜默认人数 | int | （无） |  |
| `announceLevelUp` | 升级时让她顺口提一句 | bool | （无） |  |
| `allowReset` | 允许任何人重置好感度 | bool | （无） |  |
| `ownerQq` | 主人 QQ 号（逗号分隔；留空=沿用机器人管理里绑定的管理员） | string | （无） |  |
| `ownerScore` | 主人显示的固定分数 | int | （无） |  |
| `levelThresholds` | 等级门槛（4 个递增数字，逗号分隔） | string | （无） |  |
| `verbose` | 在控制台记录每次加分 | bool | （无） |  |

## 风险与边界

- 插件是会被 import 执行的代码，装之前请先看「检查」结果与上面的配置项。
- 安装器会拦截 os.system / subprocess / eval / exec / socket / ctypes / pickle / winreg 等用法；本包已通过该检查。
- 主动发言、外发类能力默认关闭，必须由你在插件页显式启用才会生效。
- 本页说明取自源包清单，未对插件行为做额外审计；第三方插件的行为自负。
